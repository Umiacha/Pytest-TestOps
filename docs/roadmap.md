# Roadmap

## Phase 0 — Repository skeleton

Цель: создать базовую структуру проекта и зафиксировать направление.

Результат:

- README.md;
- базовая структура директорий;
- короткий roadmap;

## Phase 1 — Demo algorithms

Цель: создать demo-проект с алгоритмическими задачами и pytest-тестами.

Результат:

- несколько алгоритмов;
- pytest-тесты;
- разные размеры входных данных;
- ручной запуск тестов.

## Phase 2 — Local pytest plugin

Цель: написать первый pytest-плагин.

Результат:

- pytest marker;
- сбор времени выполнения;
- простой JSON-отчет;
- локальный запуск без backend.

## Phase 3 — Statistics and comparison

Цель: научиться сравнивать несколько запусков.

Результат:

- сохранение истории;
- сравнение запусков;
- простые агрегаты: min, max, avg, median.

## Phase 4 — Backend

Цель: добавить API для приема отчетов.

Результат:

- FastAPI backend;
- endpoint для загрузки report.json;
- хранение данных.

## Phase 5 — Dashboard

Цель: визуализировать результаты.

Результат:

- таблицы;
- графики;
- сравнение коммитов.

## Later — Go runner

Go будет добавлен позже как отдельный runner для запуска тестов, timeout, logs и управления процессом.
