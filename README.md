# TestOps Observatory

Учебный pet-проект для сбора и анализа статистики тестовых и алгоритмических запусков.

Идея проекта: pytest-плагин собирает данные о времени выполнения, памяти и параметрах запуска, а затем эти данные можно сравнивать между коммитами и разными размерами входных данных.

Проект вдохновлен задачами тестирования, performance analysis и test observability.

- история запусков;
- сравнение между коммитами;
- разные размеры входных данных;
- простая аналитика;
- дальнейшая визуализация.

На ранних этапах измерения будут приблизительными.

## Планируемый MVP

1. Создать demo-проект с алгоритмическими задачами.
2. Написать pytest-плагин, который собирает duration и простые memory metrics.
3. Сохранять результат в JSON-файл.
4. Научиться сравнивать несколько запусков.
5. Позже добавить backend и dashboard.
